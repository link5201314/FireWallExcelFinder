# 離線防火牆 Excel IPv4 位址掃描器

## Problem Statement

使用者需要在無外部網路連線的環境中，批次檢查多份可能具有不同工作表與欄位結構的防火牆 Excel 規則檔，確認其中是否包含目標 IPv4 位址、位址範圍或 CIDR 網段。手動逐檔檢查耗時且容易遺漏；只依賴欄位標題或固定表格結構，也可能錯過藏在其他工作表、備註或群組成員欄位中的位址資訊。使用者還需要能追溯每筆命中來源並保留可供後續篩選的報表。

## Solution

提供一個離線執行的命令列工具，讀取目標規則文字檔並逐格掃描指定目錄中的 `.xlsx` 活頁簿。工具支援選擇工作表與是否遞迴掃描子目錄，以 IPv4 整數區間交集判定目標規則與 Excel 位址 Token 是否命中，並輸出可追溯至檔案、工作表及儲存格位置的摘要與明細。工具使用唯讀、低記憶體的工作簿讀取方式；檔案或規則錯誤會產生警告並依錯誤類型略過或回報，不因單一 Excel 檔案問題中斷整批掃描。

## User Stories

1. As a 防火牆管理人員, I want 在沒有網路連線的環境執行掃描, so that 規則資料不必離開本機且符合離線作業限制。
2. As a 防火牆管理人員, I want 指定 Excel 檔案目錄, so that 我可以掃描選定的規則資料集。
3. As a 防火牆管理人員, I want 預設只掃描指定目錄的第一層, so that 掃描範圍可預期且不會意外擴大。
4. As a 防火牆管理人員, I want 使用遞迴選項掃描子目錄, so that 我能在需要時一次檢查分層存放的規則檔。
5. As a 防火牆管理人員, I want 工具不追蹤符號連結, so that 掃描不會意外延伸至指定目錄之外。
6. As a 防火牆管理人員, I want 工具忽略 Excel 暫存鎖定檔, so that 開啟中的活頁簿不會被當作正式輸入檔處理。
7. As a 防火牆管理人員, I want 指定目標規則檔路徑並可使用預設檔名, so that 我能快速執行常見掃描，也能套用不同目標清單。
8. As a 防火牆管理人員, I want 以空白行與整行註解整理目標清單, so that 規則檔易於閱讀與維護。
9. As a 防火牆管理人員, I want 目標檔支援 UTF-8 BOM, so that 常見文字編輯器產生的檔案不會使第一條規則解析失敗。
10. As a 防火牆管理人員, I want 以單一 IPv4 位址作為目標規則, so that 可尋找精確主機位址及包含該位址的 Excel 範圍。
11. As a 防火牆管理人員, I want 以完整 IPv4 起訖位址表示範圍, so that 可指定跨越末碼簡寫限制的位址區間。
12. As a 防火牆管理人員, I want 以同一 `/24` 內的末碼簡寫範圍表示目標, so that 常見的小型網段範圍可以簡潔輸入。
13. As a 防火牆管理人員, I want 以 CIDR 表示目標網段, so that 可直接檢查標準子網範圍。
14. As a 防火牆管理人員, I want 格式錯誤或非法的目標規則附帶行號警告並被略過, so that 其他有效規則仍可繼續掃描且錯誤來源可修正。
15. As a 防火牆管理人員, I want 掃描所有工作表中的所有儲存格, so that 位址不論出現在何種欄位或工作表都能被發現。
16. As a 防火牆管理人員, I want 可選擇一個或多個工作表名稱關鍵字, so that 我能縮小掃描範圍；關鍵字採不區分大小寫的部分比對，符合任一關鍵字即納入。
17. As a 防火牆管理人員, I want Excel 儲存格內的 IPv4、CIDR、完整範圍及簡寫範圍都能被解析, so that 不同文字形式的位址資訊皆可參與比對。
18. As a 防火牆管理人員, I want 換行字元不妨礙儲存格內位址辨識, so that 同一格多行文字中的位址也能被掃描。
19. As a 防火牆管理人員, I want 依位址區間交集而非字串相等判定命中, so that 單一位址、範圍與網段之間的包含或重疊都能正確識別。
20. As a 防火牆管理人員, I want 同一格內多個 Token 或多條目標規則的各種命中都被保留, so that 報表不會因同一格已有一筆命中而漏掉其他命中。
21. As a 防火牆管理人員, I want 相同檔案、工作表、座標、原始目標規則與 Token 的重複命中只列一次, so that 報表簡潔且不重複。
22. As a 防火牆管理人員, I want 命中明細記錄檔案、原始目標規則、實際 Token、工作表與儲存格座標, so that 我可以回到來源活頁簿驗證結果。
23. As a 防火牆管理人員, I want 每筆命中附上以 Token 為中心的約 100 字上下文, so that 我可以在不開啟活頁簿的情況下理解命中背景。
24. As a 防火牆管理人員, I want 詳細模式顯示命中儲存格的完整文字, so that 我能調查上下文節錄不足以說明的案例。
25. As a 防火牆管理人員, I want 查看掃描檔案數、有效目標規則行數與不同位址區間數, so that 我可以確認掃描範圍與目標清單解析結果。
26. As a 防火牆管理人員, I want 將報告輸出為純文字, so that 我能快速閱讀或存檔掃描結果。
27. As a 防火牆管理人員, I want 將報告輸出為 CSV 並以每筆命中一列呈現, so that 我能使用試算表或其他工具篩選與彙整結果。
28. As a 防火牆管理人員, I want 未指定報告檔時在 Console 查看命中明細, so that 我能立即檢視一次性掃描結果。
29. As a 防火牆管理人員, I want 即使報告寫入檔案，掃描摘要仍顯示在 Console, so that 我無須開啟報告便能確認執行概況。
30. As a 防火牆管理人員, I want 警告輸出至標準錯誤, so that 命中報告可保持乾淨並便於批次作業分流記錄。
31. As a 防火牆管理人員, I want 單一活頁簿格式錯誤、鎖定或無法讀取時被略過並收到警告, so that 批次作業能完成其餘檔案的掃描。
32. As a 批次作業維護者, I want 成功但零命中的執行回報成功狀態, so that 沒有命中不會被誤判為程式錯誤。
33. As a 批次作業維護者, I want 輸入或目標檔致命錯誤與部分活頁簿讀取失敗能以不同結束狀態區分, so that 自動化流程可以依執行結果採取不同處置。

## Implementation Decisions

- 交付一個使用 `argparse` 的 Python CLI 工具；預設掃描目錄為目前目錄，預設目標規則檔為 `targets.txt`。提供目錄、目標檔、報告輸出、工作表篩選、詳細輸出及遞迴掃描參數；遞迴預設關閉。
- 維持專案 Python 3.10+ 支援範圍。唯一外部執行期依賴為 `openpyxl`；其他功能使用 Python 標準庫。執行期間不呼叫外部 API 或網路服務。
- 以 `openpyxl` 唯讀、`data_only=True` 模式讀取 `.xlsx`，逐格檢查所有符合篩選條件的工作表。將儲存格換行字元正規化後，依 CIDR、範圍、單一 IPv4 的順序找出候選 Token；非法的儲存格候選安靜略過。
- 目標規則支援 IPv4 單一位址、完整 IPv4 起訖範圍、同一 `/24` 的末碼簡寫範圍及 CIDR。CIDR 使用 `strict=False` 正規化；範圍端點須有效且起始不大於結束。末碼簡寫的端點須在 0–255，且只表示同一 `/24`。
- 目標檔以 UTF-8（含 BOM）解碼；空白行與以 `#` 開頭的整行忽略。格式錯誤行在標準錯誤輸出包含行號的警告並略過。有效目標規則行保留原始文字及來源行號；有效行數與去重後的不同位址區間數分開統計。
- IPv4 位址與 CIDR 解析為閉區間；當兩區間滿足 `max(start_a, start_b) <= min(end_a, end_b)` 即為命中。IPv6 不在本次支援範圍。
- 預設只列出指定目錄直接子項；啟用遞迴時才檢查子目錄。符號連結檔案及目錄一律略過，並排除以 `~$` 開頭的 Excel 暫存鎖定檔。
- 工作表關鍵字採不區分大小寫的部分字串比對；提供多個關鍵字時採 OR 條件。未提供關鍵字時掃描所有工作表。
- 命中紀錄保留原始目標規則及來源行號、原始位址 Token、檔名、工作表名稱、儲存格列欄座標及上下文。上下文以 Token 為中心截取約 100 字；詳細模式改為提供儲存格完整文字。以檔案、工作表、座標、目標規則來源及 Token 組成去重鍵。
- 支援 `.txt` 與 `.csv` 報告；CSV 每筆命中一列。輸出報告檔時摘要仍輸出至 Console；未指定報告檔時摘要及命中明細輸出至 Console。警告輸出至標準錯誤。
- 零命中視為成功；無效輸入或目標檔案造成的致命錯誤與部分 Excel 檔案讀取失敗須使用不同的非成功結束狀態。單一檔案錯誤僅使該檔案略過，不中止其他檔案掃描。

## Testing Decisions

- 以 CLI 入口作為單一最高層測試接縫；使用臨時目錄、臨時目標檔及程式化建立的 `.xlsx` 活頁簿，驗證外部可觀察行為，不測試私有函式或內部實作細節。
- 驗證命令列參數預設值與選項、目標規則解析與警告、位址區間交集、工作表部分比對、預設非遞迴與遞迴掃描、符號連結和暫存檔排除、所有工作表儲存格掃描、命中明細及去重、上下文與詳細模式、文字及 CSV 報告、Console 摘要與標準錯誤警告，以及結束狀態。
- 建立含多工作表、多種 Token、儲存格換行、無效 Token、重複目標規則、損毀或不可讀活頁簿的測試資料，確認單一輸入錯誤不阻止其餘檔案完成掃描。
- 專案目前沒有既有 Python 原始碼或測試套件，故沒有可沿用的測試先例；首次新增測試應只依賴標準測試設施及專案既有的 `openpyxl`，且不得發出網路請求。

## Out of Scope

- IPv6 位址與網段解析或比對。
- GUI、Web 介面、外部 API、遠端儲存或網路服務。
- 修改、標記或回寫來源 Excel 活頁簿。
- 掃描 `.xls`、`.xlsm` 或其他非 `.xlsx` 格式。
- 讀取公式本身以補足沒有快取結果的公式儲存格；`data_only=True` 只能提供 Excel 儲存的最後計算結果，沒有快取時可能無法取得公式內容。
- 對 Excel 儲存格中的非法 IPv4 外觀候選逐筆發出警告。
- 自動解密密碼保護活頁簿或修復損毀檔案。

## Further Notes

- CLI 預設介面：`-d/--dir`、`-t/--target`、`-o/--output`、`-s/--sheets`、`-v/--verbose`，以及 `-r/--recursive`。報告輸出僅接受 `.txt` 與 `.csv`。
- `read_only=True` 及逐格掃描是為降低大量活頁簿的記憶體使用；掃描時間仍取決於檔案數量、工作表大小及解壓縮成本。
