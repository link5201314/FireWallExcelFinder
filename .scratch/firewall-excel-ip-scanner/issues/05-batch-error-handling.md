# 05: 批次錯誤處理與結束狀態

**What to build:** 使用者能在批次掃描中辨識致命輸入錯誤與部分活頁簿讀取失敗；個別檔案異常不會阻止其餘檔案完成掃描。

**Blocked by:** 02: IPv4 範圍與 CIDR 交集比對.

**Status:** ready-for-agent

- [ ] 無效的掃描目錄或無法讀取的目標檔會輸出清楚錯誤並以非成功狀態結束。
- [ ] 損毀、鎖定或無法讀取的活頁簿輸出警告並略過，批次仍繼續掃描其他檔案。
- [ ] 零命中回報成功；致命輸入錯誤與部分活頁簿讀取失敗使用可區分的非成功結束狀態。
- [ ] 警告輸出至標準錯誤；以 CLI 行為測試繼續掃描及各種結束狀態。
