# 01: PySide6 GUI 掃描基本流程

**What to build:** 防火牆管理人員能啟動 PySide6 視窗，選擇 Excel 掃描目錄與目標規則檔，在背景執行掃描，並以檔案位置樹檢視可追溯的命中紀錄，同時保留原有 CLI 使用方式。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] GUI 可由清楚的啟動方式開啟；PySide6 列為執行期相依性，專案 lockfile 在環境可用時同步更新。
- [ ] 使用者可輸入或以目錄選擇對話框指定 Excel 目錄，並選擇既有目標規則檔；預設值遵循 CLI 現況。
- [ ] 按下開始後，GUI 在背景執行緒掃描，不阻塞主執行緒；提供處理狀態／進度及取消操作，並避免重複啟動掃描。
- [ ] 成功完成時，命中以 `file → sheet → coordinate` 樹狀結構呈現，相同節點鍵合併，明細可追溯目標行、原始規則、Token 與上下文。
- [ ] 顯示基本掃描摘要、零命中狀態及輸入錯誤／活頁簿部分失敗提示；單一活頁簿讀取失敗不會中止其他檔案。
- [ ] 取消掃描後明確顯示取消狀態，丟棄未完成命中，不將部分結果呈現為完整結果。
- [ ] GUI 與 CLI 共用掃描及比對邏輯；既有 CLI 參數、輸出及測試維持相容。
- [ ] 以頂層 GUI 工作流程測試建立臨時 Excel fixture、啟動掃描並驗證可觀察結果；測試可在 Qt offscreen 環境執行，並完整執行既有 CLI 測試。
