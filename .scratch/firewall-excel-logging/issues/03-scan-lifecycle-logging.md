# 03: 掃描生命週期與隱私邊界

**What to build:** 日誌能重建一次掃描的脈絡：INFO 記錄掃描開始參數（目錄、是否遞迴、工作表關鍵字、選取規則數）、完成統計與報告寫入結果；DEBUG 記錄每個檔案的處理結果（僅檔名與該檔命中數）。日誌中不出現儲存格完整文字、目標規則原始行或命中 Token 的上下文。

**Blocked by:** 02（輪替日誌檔）

**Status:** ready-for-agent

- [ ] 掃描開始時以 INFO 記錄目錄、遞迴設定、工作表關鍵字與本次選取規則數。
- [ ] 掃描完成時以 INFO 記錄掃描檔案數、命中數、有效規則數、部分失敗狀態與是否取消。
- [ ] 報告寫入成功或失敗時以 INFO 或 ERROR 記錄結果與輸出路徑。
- [ ] 每個檔案的處理結果以 DEBUG 記錄，只包含檔名與該檔命中數，不逐格記錄。
- [ ] 日誌檔與 UI sink 中都不出現儲存格完整文字、目標規則原始行或 Token 上下文。
- [ ] 日誌等級調整不改變掃描結果、命中內容、報告欄位或 GUI 樹狀檢視。
- [ ] 測試以含敏感文字的儲存格執行掃描，斷言該文字與目標規則原始行不出現在日誌檔。
- [ ] 測試涵蓋 INFO 與 DEBUG 等級下可見的生命週期訊息差異。
- [ ] `uv run pytest` 全綠，`uv run ruff check` 無新錯誤。

**Definition of Done:** 上述驗收項目全部通過；只靠日誌檔即可說出一次掃描的範圍、結果與報告狀態，且不洩漏儲存格內容。
