# 02: GUI 目標規則編輯與逐條選取

**What to build:** 防火牆管理人員能在 GUI 直接載入、新增、編輯及儲存目標規則，逐條選取本次掃描規則，並確保掃描使用的目標行號與已儲存檔案一致。

**Blocked by:** 01: PySide6 GUI 掃描基本流程。

**Status:** ready-for-agent

- [ ] 使用者可在 GUI 編輯單一目標清單，載入既有文字檔、儲存回目前檔案或另存新檔；文字檔格式相容既有目標檔。
- [ ] 編輯內容保留空白行與整行註解；有效目標規則可逐條勾選，預設全部選取，選取狀態只存在本次 GUI 工作階段，不寫入檔案或跨次保存。
- [ ] 格式錯誤的規則行顯示實際行號及原因並略過；掃描只使用已勾選的有效規則。無任何有效規則或無任何已選規則時，阻止掃描並提示原因。
- [ ] 目標內容未儲存時，開始掃描必須先儲存；有目前檔案路徑時存回該檔，沒有路徑時要求另存新檔。使用者取消儲存或儲存失敗時不得啟動掃描。
- [ ] 掃描與命中明細的 `target_line` 以儲存後文字檔的實際 1-based 行號為準，空白行與註解行也計入；同一條有效規則的原始文字與行號可追溯。
- [ ] 摘要區分完整目標清單有效規則數、本次選取規則數、完整清單不同位址區間數及本次選取規則的不同位址區間數；命中只來自本次選取規則。
- [ ] GUI 整合測試涵蓋載入／儲存／另存、錯誤規則提示、暫時選取、執行前存檔、取消或儲存失敗不掃描，以及行號與命中結果一致。
