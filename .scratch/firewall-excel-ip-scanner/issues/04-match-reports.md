# 04: 可追溯的 TXT 與 CSV 報表

**What to build:** 使用者能查看或匯出完整的命中紀錄，並從每筆結果追溯目標規則、位址 Token 與 Excel 儲存格上下文。

**Blocked by:** 02: IPv4 範圍與 CIDR 交集比對.

**Status:** ready-for-agent

- [ ] 支援純文字及 CSV 報告；CSV 每筆命中一列，報告包含目標規則、實際位址 Token、檔案、工作表及列欄座標。
- [ ] 未指定報告檔時，Console 顯示摘要與命中明細；指定報告檔時，摘要仍顯示於 Console。
- [ ] 每筆命中提供以 Token 為中心約 100 字的上下文；詳細模式提供儲存格完整文字。
- [ ] 以檔案、工作表、座標、目標規則來源及 Token 去重，保留其他不同命中。
- [ ] 以 CLI 行為測試文字／CSV 報告、上下文、詳細模式、摘要及去重。
