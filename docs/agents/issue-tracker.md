# Issue tracker: Local Markdown

Issues and specs for this repo live as Markdown files under `.scratch/`.

## Conventions

- One feature per directory: `.scratch/<feature-slug>/`
- The feature spec is `spec.md` in that directory.
- Implementation issues are one file per ticket under `issues/`, numbered from `01`.
- Each issue has a `Status:` line near the top using the configured triage label.
- Comments and conversation history append under a `## Comments` heading.

## When a skill says "publish to the issue tracker"

Create or update the relevant feature directory and its `spec.md` or issue file.

## When a skill says "fetch the relevant ticket"

Read the referenced Markdown file.
