# 02: IPv4 範圍與 CIDR 交集比對

**What to build:** 使用者能以單一位址、完整 IPv4 範圍、同一 `/24` 的末碼簡寫或 CIDR 表示目標，並找出 Excel 位址 Token 與目標區間有重疊的命中。

**Blocked by:** 01: 單一 IPv4 位址的離線掃描流程.

**Status:** ready-for-agent

- [ ] 目標規則支援單一 IPv4、完整起訖範圍、同一 `/24` 的末碼簡寫範圍與 CIDR；CIDR 以 `strict=False` 正規化。
- [ ] 儲存格文字依 CIDR、範圍、單一 IPv4 的順序解析 Token，換行字元不會阻礙辨識；非法的儲存格候選略過。
- [ ] 以閉區間交集判定命中；非法目標規則列出行號警告後略過，其他規則仍可使用。
- [ ] 目標檔支援 UTF-8 BOM、空白行及整行註解；摘要分別列出有效目標規則行數與不同位址區間數。
- [ ] 以 CLI 行為測試位址格式、交集邊界、錯誤規則處理及有效規則統計。
