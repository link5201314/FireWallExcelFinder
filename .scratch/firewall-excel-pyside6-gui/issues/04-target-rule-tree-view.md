# 04: 目標規則樹狀檢視與結果操作

**What to build:** 防火牆管理人員能從目標規則角度查看同一批命中，並在目標規則檢視與檔案位置檢視之間即時切換、展開或摺疊結果，而不必重新掃描 Excel。

**Blocked by:** 01: PySide6 GUI 掃描基本流程。

**Status:** ready-for-agent

- [ ] 在既有檔案位置模式之外，新增目標規則模式；根節點以 `(target_line, target)` 為鍵，相同鍵值合併，其下依 `file → sheet → coordinate` 分組。
- [ ] 兩種模式切換只重新呈現已完成掃描的命中紀錄，不重讀 Excel、不重新比對。
- [ ] 兩種模式都保留可追溯明細，至少能檢視 `file`、`sheet`、`coordinate`、`target_line`、`target`、`token` 及上下文；目標規則模式不得因合併根節點而遺失來源位置。
- [ ] 提供全部展開及全部摺疊操作，並明確標示目前檢視模式與各層節點意義。
- [ ] 顯示完整掃描摘要：掃描檔案數、完整清單有效規則數、本次選取規則數、本次選取規則的不同位址區間數、命中數及部分失敗狀態；零命中時顯示友善空狀態。
- [ ] 結果以適用於大量命中的 Qt model/view 或等效方式呈現，避免樹狀結果建構阻塞 UI 事件處理。
- [ ] GUI 整合測試驗證兩種模式的節點合併與命中追溯、全部展開／摺疊、摘要內容及切換時不重新掃描；使用臨時 fixture，不依賴使用者活頁簿。
