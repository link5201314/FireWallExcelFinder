# 03: GUI 掃描篩選與報告輸出

**What to build:** 防火牆管理人員能在 GUI 調整既有 CLI 的工作表、遞迴及詳細模式選項，並可將本次選取目標規則的命中輸出為 TXT 或 CSV 報告。

**Blocked by:** 02: GUI 目標規則編輯與逐條選取。

**Status:** ready-for-agent

- [ ] GUI 提供工作表名稱關鍵字篩選；多個關鍵字沿用不區分大小寫、部分比對及 OR 語意，未填時掃描全部工作表。
- [ ] GUI 提供遞迴掃描子目錄選項，預設關閉，與 CLI 行為一致。
- [ ] GUI 提供簡要上下文／完整儲存格文字選項；簡要模式沿用現有上下文節錄。
- [ ] 使用者可選擇不輸出報告、輸出 TXT 或 CSV，並可透過檔案選擇對話框指定路徑；未選擇報告時，命中仍顯示在 GUI。
- [ ] CSV 報告使用 UTF-8 BOM，欄位與既有報告相容；報告只包含本次勾選的有效目標規則，且 `target_line` 對應已儲存目標檔中的實際行號。
- [ ] 正常完成或部分活頁簿失敗時，報告內容及 GUI 摘要都能反映實際結果與部分失敗狀態。
- [ ] 使用者取消掃描時，不提交不完整報告，也不留下看似完整的新報告；既有同名報告不可因取消而遭不完整內容覆寫。
- [ ] GUI 整合測試驗證工作表篩選、遞迴、上下文模式、無輸出／TXT／CSV、CSV BOM、僅輸出已選規則及取消時不提交報告；既有 CLI 測試仍通過。
