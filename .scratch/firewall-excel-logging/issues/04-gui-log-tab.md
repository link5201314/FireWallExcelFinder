# 04: GUI 日誌分頁

**What to build:** GUI 底部改為「日誌」與「警告」兩個分頁。「日誌」分頁即時顯示符合 `ui` 等級的日誌，保留最近 1,000 行、自動捲到最新一筆，並提供「清除」與「開啟日誌資料夾」；「警告」分頁維持只顯示掃描結果 warnings，不受 `ui` 等級影響。日誌從背景執行緒安全地送回主執行緒，關閉視窗後不再持有 widget。

**Blocked by:** 03（掃描生命週期與隱私邊界）

**Status:** ready-for-agent

- [ ] GUI 底部顯示「日誌」與「警告」兩個分頁，預設選中「日誌」。
- [ ] 「日誌」分頁唯讀，顯示時間、等級、logger 與訊息，並自動捲到最新一筆。
- [ ] 「日誌」分頁只保留最近 1,000 行，超過時丟棄最舊的訊息。
- [ ] 「清除」按鈕清空日誌分頁，不影響「警告」分頁。
- [ ] 「開啟日誌資料夾」按鈕開啟 `%LOCALAPPDATA%\FireWallExcelFinder\logs`；測試以替身攔截外部開啟動作，不真的啟動檔案總管。
- [ ] `ui=DEBUG` 時日誌分頁看得到每檔處理訊息；`ui=ERROR` 時 warning 不出現在日誌分頁。
- [ ] `ui=ERROR` 時，「警告」分頁仍顯示掃描結果 warnings；狀態列、進度條與摘要文字不受日誌等級影響。
- [ ] 背景執行緒產生的日誌經 Qt signal 回主執行緒更新面板，不從背景執行緒直接操作 widget。
- [ ] 建立主視窗時完成日誌初始化；同一程序內重複建立視窗不會產生重複行；關閉視窗時解除並移除自家 handler。
- [ ] 測試以暫存 `%LOCALAPPDATA%` 建立 `MainWindow`，涵蓋等級過濾、分頁獨立、清除、行數上限、重複初始化與關閉視窗。
- [ ] `uv run pytest` 全綠，`uv run ruff check` 無新錯誤。

**Definition of Done:** 上述驗收項目全部通過；GUI 使用者不開 console 也能看到日誌，且警告分頁與既有操作回饋完全不受影響。
