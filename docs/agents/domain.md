# Domain Docs

This is a single-context repository.

## Before exploring

- Read the existing root `CONTEXT.md` for the project's domain vocabulary.
- Read root `GLOSSARY.md` or `GLOSSARY-MAP.md` if either is added later.
- Read relevant decisions under `docs/adr/` if present.
- If a document does not exist, proceed without treating its absence as a blocker.

## Use the domain vocabulary

Use terms from the domain documentation in issue titles, proposals, and tests. Surface contradictions with existing definitions rather than silently changing terminology.

## Layout

The current single-context glossary is `CONTEXT.md`; repository-wide ADRs belong under `docs/adr/`.
