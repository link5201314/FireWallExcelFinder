# 03: 目錄與工作表範圍選擇

**What to build:** 使用者能選擇是否遞迴掃描子目錄，並依工作表名稱關鍵字縮小掃描範圍，同時維持安全且可預期的檔案選取行為。

**Blocked by:** 01: 單一 IPv4 位址的離線掃描流程.

**Status:** ready-for-agent

- [ ] 提供遞迴掃描選項，預設關閉；啟用時掃描子目錄但不追蹤符號連結。
- [ ] 可提供一個或多個工作表名稱關鍵字；採不區分大小寫的部分比對，多個關鍵字符合任一個即可。
- [ ] 未提供工作表關鍵字時掃描全部工作表；所有範圍選項都保留略過暫存鎖定檔及符號連結的行為。
- [ ] 以 CLI 行為測試預設非遞迴、遞迴、工作表篩選及不追蹤符號連結。
