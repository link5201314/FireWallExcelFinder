# PySide6 桌面介面與互動式命中檢視

**Status:** ready-for-agent

## Problem Statement

防火牆管理人員目前只能透過命令列和外部目標文字檔設定掃描，並以文字或 CSV 檢視結果。這使得直接編輯、挑選本次要套用的目標規則、瀏覽 Excel 目錄及追蹤大量命中都不夠直覺；也無法在同一個介面中以檔案位置或目標規則兩種角度整理命中紀錄。

## Solution

在既有離線 CLI 掃描器上新增 PySide6 桌面應用程式，讓使用者可透過視窗設定掃描、編輯及選取目標規則、啟動或取消背景掃描，並以可展開／摺疊的樹狀結果檢視命中。GUI 與 CLI 共用相同的位址解析、掃描、命中去重和報告邏輯；既有 CLI 用法與外部行為維持相容。

結果提供兩種不需重新掃描即可切換的檢視：依 `file → sheet → coordinate` 分組，或依 `(target_line, target) → file → sheet → coordinate` 分組。掃描摘要、警告及報告均能在 GUI 工作流程中取得。

## User Stories

1. As a 防火牆管理人員, I want 以視窗啟動離線掃描器, so that 我不必記憶命令列參數即可執行常見掃描。
2. As a 防火牆管理人員, I want 選擇或輸入 Excel 目錄, so that 我能明確指定本次掃描範圍。
3. As a 防火牆管理人員, I want 透過目錄選擇對話框挑選 Excel 目錄, so that 不必手動輸入完整路徑。
4. As a 防火牆管理人員, I want 逐條新增、編輯和刪除目標規則, so that 我能直接在 GUI 維護搜尋清單。
5. As a 防火牆管理人員, I want 載入既有目標文字檔並在介面中編輯, so that 我能沿用現有規則檔與工作方式。
6. As a 防火牆管理人員, I want 將目標清單儲存回檔案或另存新檔, so that 編輯內容能成為可重複使用的來源。
7. As a 防火牆管理人員, I want 逐條勾選本次要套用的有效目標規則, so that 能以同一份目標清單執行不同範圍的掃描。
8. As a 防火牆管理人員, I want 目標規則選取狀態僅暫存於目前 GUI 工作階段, so that 暫時性篩選不會意外修改目標檔案。
9. As a 防火牆管理人員, I want 格式錯誤的目標行顯示原始行號及原因並略過, so that 其他有效規則仍可使用且錯誤容易修正。
10. As a 防火牆管理人員, I want 在沒有任何有效或已選取規則時收到明確提示且不啟動掃描, so that 不會誤以為已完成有效查找。
11. As a 防火牆管理人員, I want 在編輯尚未儲存時開始掃描會先被要求儲存, so that 報告中的 `target_line` 能對應到實際儲存的目標檔內容。
12. As a 防火牆管理人員, I want 目標檔尚未指定時透過「另存新檔」完成儲存, so that 新建清單也能作為掃描來源。
13. As a 防火牆管理人員, I want 在儲存對話框取消或儲存失敗時不開始掃描, so that 掃描所依據的規則來源不會與報告行號不一致。
14. As a 防火牆管理人員, I want 設定一個或多個工作表名稱關鍵字, so that 能沿用 CLI 的不分大小寫、部分符合及 OR 篩選行為。
15. As a 防火牆管理人員, I want 選擇是否遞迴掃描子目錄, so that 能控制掃描深度並沿用預設非遞迴行為。
16. As a 防火牆管理人員, I want 切換簡要上下文或完整儲存格文字, so that 能依檢視需求平衡資訊量與易讀性。
17. As a 防火牆管理人員, I want 選擇不輸出報告、輸出 TXT 或輸出 CSV, so that 能按用途檢視或留存結果。
18. As a 防火牆管理人員, I want 透過檔案選擇對話框指定報告位置, so that 不必手動輸入完整輸出路徑。
19. As a 防火牆管理人員, I want GUI 掃描在背景執行並呈現目前狀態或進度, so that 長時間掃描時介面仍可回應。
20. As a 防火牆管理人員, I want 取消進行中的掃描, so that 可停止不再需要的工作。
21. As a 防火牆管理人員, I want 取消後看見明確狀態且未完成結果不被當成完整結果, so that 不會誤用部分掃描資料。
22. As a 防火牆管理人員, I want 依檔案位置檢視命中並合併相同的檔案、工作表及座標節點, so that 能快速定位 Excel 中的命中位置。
23. As a 防火牆管理人員, I want 依目標規則檢視命中並合併相同來源行號及規則文字, so that 能了解每條目標規則命中哪些來源位置。
24. As a 防火牆管理人員, I want 在兩種樹狀檢視間切換而不重新掃描, so that 能從不同角度檢視同一批命中。
25. As a 防火牆管理人員, I want 展開或摺疊全部樹節點, so that 能快速聚焦於結果的不同層級。
26. As a 防火牆管理人員, I want 在命中明細中查看目標來源行、原始目標文字、位址 Token 及上下文, so that 每筆結果都能追溯及驗證。
27. As a 防火牆管理人員, I want 查看掃描檔案數、有效規則總數、本次選取規則數、不同位址區間數及命中數, so that 能確認本次執行範圍與結果。
28. As a 防火牆管理人員, I want 在沒有命中時看到友善的空結果訊息, so that 能區分零命中與介面未執行。
29. As a 防火牆管理人員, I want 看見損毀或不可讀活頁簿等部分失敗警告, so that 能知道哪些輸入檔未能完成掃描。
30. As a 防火牆管理人員, I want 輸入路徑或報告輸出錯誤在 GUI 中明確呈現, so that 不必查看隱藏 Console 才能診斷問題。
31. As a 防火牆管理人員, I want 選擇 CSV 時得到帶 UTF-8 BOM 的報告, so that Windows Excel 能正確顯示中文字元。
32. As a 防火牆管理人員, I want 既有 CLI 參數與輸出行為維持不變, so that 自動化工作流程不因新增 GUI 而中斷。
33. As a 防火牆管理人員, I want GUI 與 CLI 使用相同掃描規則, so that 同一輸入不會因使用不同介面而產生不一致的命中結果。

## Implementation Decisions

- 新增 PySide6 桌面介面；維持 Python 3.10+ 支援並將 PySide6 納入執行期相依性。使用專案既有的 `uv` 環境管理方式。
- 維持單一目標清單，不引入命名群組。目標文字檔每行仍代表一條規則；空白行與整行 `#` 註解保留在可編輯內容中，但不作為可選規則。
- GUI 呈現可編輯的目標清單，並提供已解析有效規則的逐條勾選。錯誤行顯示實際來源行號及解析錯誤；掃描時略過錯誤行。有效目標規則與不同位址區間沿用領域定義。
- 目標清單的有效規則行數與不同位址區間數依完整目標檔內容計算；本次選取規則數及本次掃描使用的不同位址區間數另行統計。命中及報告只包含本次已選取的有效規則。選取狀態不寫入目標文字檔，也不跨 GUI 工作階段保存。
- 開始掃描前檢查目標清單是否有未儲存修改。有已載入的檔案時要求儲存回該檔；沒有目前檔案路徑時要求另存新檔。只有儲存成功才可掃描；使用者取消儲存或儲存失敗則不啟動掃描。保存的文字內容與實際行號是本次掃描的唯一來源。
- 目標規則行號採儲存後文字檔的實際 1-based 行號，空白行及註解行也計入。目標行錯誤時沿用既有略過策略；本次沒有任何有效且已選取規則時，GUI 阻止掃描並說明原因。
- 保留既有單一 IPv4、同一 `/24` 末碼簡寫範圍、完整 IPv4 範圍、CIDR、IPv4 區間交集、儲存格 Token 擷取、工作表篩選、唯讀活頁簿掃描、符號連結與 Excel 暫存鎖定檔排除，以及命中去重行為。GUI 不自行複製或改寫一套不一致的比對邏輯。
- GUI 將 CLI 目前可控制的掃描目錄、目標規則、工作表關鍵字、遞迴選項、詳細模式及 TXT/CSV 報告輸出提供對應操作。預設值與 CLI 一致。
- Excel 掃描放在 Qt 背景工作執行緒執行，透過 Qt signals 安全回傳進度、命中、警告、摘要及完成狀態。主執行緒不執行掃描，也不以阻塞等待工作完成。
- 掃描期間避免重複啟動及會導致設定與工作狀態不一致的操作；取消請求使背景工作安全停止。取消的掃描丟棄本次未完成命中，不將不完整結果呈現為完整結果，也不覆寫指定報告。
- 掃描完整結束時，允許部分活頁簿失敗但繼續處理其他檔案；報告及摘要標示部分失敗狀態。發生取消時不提交本次報告；報告應避免取消或失敗的寫入流程留下看似完整的新報告。
- 檔案位置檢視以 `file → sheet → coordinate` 分組，節點鍵為對應欄位值；重複鍵只顯示一個節點。座標下顯示該位置的每筆命中明細，至少包含 `target_line`、`target`、`token` 及上下文。
- 目標規則檢視以 `(target_line, target)` 作為根節點鍵；相同鍵值合併，其下依 `file → sheet → coordinate` 分組。命中明細保留 `token` 及上下文。兩種模式皆需保留每筆命中可追溯的欄位資訊。
- 切換檢視模式只重組已完成掃描的命中紀錄，不觸發 Excel 重讀或重新比對。提供全部展開與全部摺疊操作，並以適用於大量結果的 Qt model/view 或等效方式呈現。
- 摘要至少顯示掃描檔案數、完整清單有效目標規則數、本次選取規則數、本次選取規則的不同位址區間數、命中數及部分失敗狀態。無命中時顯示明確空狀態。
- 報告仍沿用既有 TXT/CSV 欄位及內容語意；CSV 使用 UTF-8 BOM。GUI 選擇不輸出檔案時，命中只呈現在 GUI。
- 輸入目錄無效、目標檔無法讀取或儲存、報告無法寫入及活頁簿讀取失敗等狀況需透過 GUI 訊息或狀態資訊呈現；單一活頁簿錯誤不得令整批掃描崩潰。
- 設定與目標清單選取狀態不跨程式執行保存；目標清單僅透過使用者明確操作載入／儲存的文字檔持久化。
- 既有 CLI 入口與參數不變；可共用邏輯可在維持外部 CLI 相容的前提下整理，但 GUI 與 CLI 的掃描核心必須是單一來源。

## Testing Decisions

- 主要新增測試接縫採 GUI 使用者工作流程整合測試：建立真實臨時 `.xlsx` 與目標文字檔，從頂層視窗的可觀察操作設定目錄和規則、啟動掃描，並驗證摘要、樹狀結果、報告、取消與錯誤提示。只替代 OS 檔案選擇對話框等外部互動，不替代掃描核心。
- GUI 測試在 headless CI 環境使用 Qt offscreen 平台，並以適合 Qt 事件迴圈的 pytest 測試工具等待背景掃描訊號與完成狀態，避免使用固定睡眠時間或直接呼叫私有 widget handler。
- 以相同的 CLI subprocess 測試接縫保留既有命令列外部行為測試；完整執行既有測試以確認 GUI 整合未造成 CLI 回歸。
- 測試需驗證有效／無效目標行、BOM 與行號一致性、未儲存時儲存後才啟動、無檔案路徑時另存新檔、取消／儲存失敗時不掃描、暫時規則選取、無選取規則阻止掃描，以及目標內容改動後的選取與驗證呈現。
- 測試需驗證檔案位置樹相同 `file`、`sheet`、`coordinate` 合併，以及目標規則樹相同 `(target_line, target)` 合併；兩種檢視皆應保留命中明細的來源行號、原始目標、Token 和上下文，切換模式不重跑掃描。
- 測試需驗證遞迴與工作表篩選、簡要／詳細上下文、TXT/CSV 輸出與 CSV BOM、零命中、部分活頁簿失敗、掃描取消丟棄未完成結果且不提交報告，以及 GUI 執行期間仍可處理事件。
- 測試只依賴程式化生成的臨時資料，不使用實際使用者防火牆活頁簿，也不發出網路請求。
- 既有測試先例是以隔離目錄、程式化 Excel fixture 和 CLI subprocess 驗證外部行為；新 GUI 測試延續外部行為原則，並將最高整合接縫放在頂層 GUI 工作流程。

## Out of Scope

- 多個命名目標群組、群組匯入／匯出或群組啟用／停用。
- 儲存目標規則的勾選狀態或跨程式執行保存視窗設定。
- IPv6、`.xls`、`.xlsm`、網路服務、遠端儲存或外部 API。
- 修改、標記或回寫來源 Excel 活頁簿。
- 自動修復或解密損毀、密碼保護的活頁簿。
- 取代或移除既有 CLI 介面、參數、報告格式或自動化相容性。
- 在 GUI 內新增與位址比對無關的 Excel 編輯或防火牆政策管理功能。

## Further Notes

- 本規格是既有離線 CLI 掃描器的 GUI 擴充規格；既有 CLI 規格中「GUI 不在範圍內」的決策適用於原 CLI 功能交付，不限制本獨立擴充功能。
- 專案領域詞彙沿用 `CONTEXT.md`：目標規則、有效目標規則行、不同位址區間、位址 Token、命中及命中紀錄。`target_line` 是文字檔來源行號，不是規則排序或命中序號。
