# 05: 日誌失敗降級

**What to build:** 日誌是輔助功能，任何設定或檔案系統問題都不能阻止程式啟動或掃描。控制檔不可讀、INI 格式錯誤、日誌目錄不可寫或 `%LOCALAPPDATA%` 缺失時，程式仍可完成掃描與輸出報告，並在當下可用的 sink 留下一筆清楚的錯誤。

**Blocked by:** 02（輪替日誌檔）、04（GUI 日誌分頁）

**Status:** ready-for-agent

- [ ] 控制檔無法讀取時使用預設等級，並在 UI sink 留下一筆警告；程式不中斷。
- [ ] INI 格式損壞或等級值非法時使用預設值，並在 UI sink 留下一筆警告；程式不中斷。
- [ ] 日誌目錄或檔案無法建立（權限不足、磁碟滿、路徑無效）時停用檔案 sink，程式照常啟動與掃描，並在 UI sink 留下一筆 ERROR。
- [ ] `%LOCALAPPDATA%` 未定義時退回使用者家目錄下的 `AppData\Local`；若仍無法建立日誌，停用檔案 sink。
- [ ] CLI 在上述情況下仍回傳原本的退出碼，stdout 報告輸出不受影響。
- [ ] GUI 在上述情況下仍可完成掃描、顯示結果，日誌分頁或狀態列能看見降級原因。
- [ ] 日誌初始化流程不得把例外拋給呼叫端；單一 sink 失敗不影響另一個 sink。
- [ ] 測試涵蓋控制檔損壞、日誌目錄不可寫、`%LOCALAPPDATA%` 缺失三種降級路徑，並斷言掃描仍成功。
- [ ] `uv run pytest` 全綠，`uv run ruff check` 無新錯誤。

**Definition of Done:** 上述驗收項目全部通過；把日誌相關路徑弄壞後，主要掃描功能仍然可用。
